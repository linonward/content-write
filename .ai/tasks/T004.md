## 用户结果

作者可在素材箱上传 `.md` 或 `.txt` 文件，保留原始文字、文件名和素材类型，并像文字素材一样查看、编辑和删除。格式或大小不符合要求时收到明确反馈。

## 范围

- 浏览器和 API 双重校验扩展名、严格 UTF-8、文件不超过 1 MiB、正文不超过 50,000 字符。
- 独立 API 接收单文件上传，限制请求体大小，提取文件名标题，持久化素材和初始版本。
- 素材箱上传交互、类型与来源文件展示、失败反馈。
- PostgreSQL 集成测试、HTTP 验证、文档和 PR。
