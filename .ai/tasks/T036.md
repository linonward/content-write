## 用户结果

作者在账号菜单“外观”中选择跟随系统、浅色或深色；选择按设备记住，刷新与新标签页立即生效，首次绘制前应用、不闪烁。未登录的落地页与登录页跟随系统或本机已有选择。

## 范围

- `globals.css` 颜色 token 改为 `light-dark(浅色, 深色)`，遮罩与浮层阴影同步；`color-scheme` 由 `html[data-theme]` 控制，无选择时跟随系统。
- `modules/theme`：存储键、解析、`<head>` 内联脚本、`useTheme` / `setTheme`、跨标签页同步、开发模式重挂载后补回属性。
- 账号菜单新增“外观”单选组（跟随系统 / 浅色 / 深色）。
- Markdown 编辑器语法高亮、光标与选区改用 token（新增直接依赖 `@codemirror/language`、`@lezer/highlight`，版本与锁文件中已有一致）。
- `docs/design-system.md` 第 2 节增加深色 token 表与对比度。

## 不包括

- 导出 HTML 与公众号草稿样式（与主题无关）。
- 设计稿 `content-write.pen` 的深色变量。
- 落地页与登录页的主题切换入口。
