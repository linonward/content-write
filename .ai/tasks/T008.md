## 用户结果

作者选定 1～10 条已整理素材，主动生成 3～5 个有来源的选题，查看理由和证据缺口，并可收藏或忽略。

## 垂直范围

- `/ideas` 选择素材、生成、轮询、列表和来源查看；不展示尚未实现的文章创建入口。
- `GET /api/ideas`、`POST /api/ideas/generate`、`PATCH /api/ideas/:id`，含用户隔离、Origin、输入、幂等、配额、版本与错误反馈。
- 持久任务、worker、选题及来源关系；确定性 mock 与来源校验。
- 素材编辑或删除后，未完成任务失效；删除后清理依赖该素材的选题。
- 单元、真实 PostgreSQL 集成测试、文档与验证记录。

## 验收

- [x] 只允许选择本人当前版本已整理的 1～10 条素材，生成 3～5 个选题。
- [x] 每项选题包含目标读者、主张、素材理由、来源、证据缺口和建议结构。
- [x] 刷新后可查看选题与任务状态，收藏和忽略持久化。
- [x] 幂等、配额、并发、来源版本、删除与跨用户隔离通过测试。

## 实施记录

采用确定性 mock：从已整理摘要、观点和角度构造 3 个选题，并明确证据缺口，不把 mock 当作真实模型。任务绑定全部所选素材版本；worker 在提交结果的同一事务中核对来源、保存选题和来源关系、记录用量与成功状态。素材删除清理依赖该素材的选题及任务；页面不展示 T009 才实现的文章创建入口。
