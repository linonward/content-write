## 用户结果

作者可保存公开网页 URL；若服务端开启抓取，可尝试提取网页文字。抓取失败仍保留链接，作者可粘贴正文并保留来源记录。未开启抓取时明确提示，并允许只保存链接。

## 范围

- 素材箱链接表单、服务端抓取开关及状态反馈。
- 独立 API 校验 URL、身份、Origin，持久化链接、正文、抓取状态与版本。
- 抓取仅允许 HTTP/HTTPS 与 80/443 端口；解析并检查 IPv4/IPv6 DNS 答案，固定经验证 IP 建连；每次重定向重新校验，最多 3 次。
- 不发送用户 Cookie；15 秒总超时、2 MiB 下载和解压限制；仅提取允许的文字类型；每用户每小时最多 10 次抓取尝试。
- 默认 `REMOTE_FETCH_ENABLED=false`；失败或关闭时不生成虚构正文。
