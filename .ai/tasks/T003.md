## 用户结果

受邀作者可在素材箱保存文字素材，查看列表与全文，修改标题和正文，删除素材。每次修改保留版本，其他用户无法读取或修改。

## 范围

- PostgreSQL 素材与版本表；删除时清除正文和版本快照。
- 独立 Hono API 的创建、列表、详情、编辑、删除；输入限制、登录校验、写入来源校验与统一错误。
- 素材箱页面的创建、查看、编辑、删除与明确反馈。
- 真实 PostgreSQL 集成测试及主分支之外的本地 HTTP 验证。
