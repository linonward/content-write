## 用户结果

作者在文章页点“预览”，看到约 375px 手机宽度的当前标题与正文（标题、段落、列表、引用、代码块、分隔线），并下载 Markdown 或 HTML 文件。预览与 HTML 导出走同一条经过清理的渲染链：Markdown 里的原始 HTML 不执行，脚本、事件属性、iframe 和不安全链接被移除，远程图片不自动加载。参考文章不会出现在预览或导出里。

## 范围

- 渲染：`apps/api/src/modules/article-export/render.ts`，remark/rehype（CommonMark），丢弃原始 HTML，图片转为链接或文字，白名单清理，链接只保留绝对 http(s)/mailto 并加 `rel`；独立 HTML 文档带禁止任何网络请求的 CSP。
- API：`GET /api/articles/:id/preview`（JSON，含清理后的 HTML 片段）、`GET /api/articles/:id/export?format=markdown|html`（附件下载）；新模块 `article-export` 按 route → service → repository 分层，只读 `articles`。
- Web：`/articles/:id/preview` 页面（导出卡片、预览提示、手机框），文章页增加“预览”入口。
- 权限与错误：未登录 401，跨用户或不存在 404，没有正文 422，格式错误 422。

## 不包括

- 发布记录与 `/articles/:id/publish`（T018）。
- 推送草稿箱（T031）；文章顶栏“预览与发布”按钮与阶段条属于 T031，本任务入口暂名“预览”。
- GFM 表格、删除线、任务列表（只支持 CommonMark）。

## 实施记录

- 渲染放在 API：预览页从 API 取已清理的 HTML 片段，Web 不引入渲染依赖、数据库或密钥；HTML 导出直接嵌入同一片段。T031 推草稿时也在 API 侧，可直接复用。没有新建共享包（只有 API 使用）。
- 图片：`![alt](https://…)` 渲染为文字链接 `[图片：alt]`，点击才打开原图；非 http(s) 或位于链接内的图片只保留文字。预览和导出都不出现 `<img>`。
- Markdown 导出是作者原文（`# 标题` 加正文），作为附件下载，不经过浏览器渲染。
- 无数据库迁移。新增依赖（API）：`unified`、`remark-parse`、`remark-rehype`、`rehype-sanitize`、`rehype-stringify`、`@types/hast`（开发）。
- 与 T030 共享的文件只做追加：`apps/api/src/app.ts` 注册路由（2 行），文章页加一个“预览”链接；未修改 `apps/api/src/modules/articles/*`。
