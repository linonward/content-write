# Phase 0 实施计划

按照 `docs/product.md` 的 T001–T024 顺序推进；仅在依赖完成后启动下游任务。每个任务覆盖可体验结果所需的界面、服务、数据、权限、失败反馈、验证与文档。主分支集成后才标完成。

T001 建立可启动 Web、数据库、迁移、worker 进程、健康检查、CI 与记录。T002 接入邀请账号。T003–T007 完成素材入口与处理。T008–T013 完成从素材到编辑的写作闭环。T014–T020 完善作者画像、预览、发布记录和反馈。T021–T024 接入真实模型、完成回归、部署与试用。

业务表随首次使用它的切片加入。真实凭证与部署环境的阻塞只影响相关任务。
