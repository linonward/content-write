## 决定

- token 名与设计稿变量同名，Tailwind 默认调色板、字体、圆角、阴影全部清空（`--color-*: initial` 等），只能用 token；`--spacing` 固定 4px。字号放在 `body`，`html` 保持浏览器默认，避免 rem 变成 14px（第一次实现时所有间距被缩成 0.875 倍，比对时发现并修正）。
- 排版角色做成 Tailwind 字号 token（`text-title-page` 等，带行高与字重）；`cn` 用 `createCn` 登记这些类名，否则会和 `text-ink` 等颜色类互相覆盖。
- shadcn 别名颜色（`primary`、`muted-foreground` 等）不再保留，全部替换为设计 token，脚本拦截再次出现。
- 按钮变体改名为 `primary`/`secondary`/`ghost`/`danger`，另加 `danger-solid` 只用于确认对话框里的最终删除；Badge 变体改为 `neutral`/`muted`/`accent`/`evidence`/`danger`/`mock`。
- 原生 `select`（素材筛选、写作框架）换成 `SelectField`；原生文件选择换成 `FileDropzone`（内部仍是带 `name` 的 file input，表单读取方式不变）。
- 素材箱列表与拆解列表的状态改为 `StatusPill`；处理状态文案统一为设计稿的“未整理 / 处理中 / 失败 / 已整理”。大纲“缺少素材”从红色改为赭黄（证据缺口不是失败）。
- 新增 `/design-system` 开发页用于比对，生产环境 `notFound()`。
- 页面标题暂用 `font-serif text-title-article`，不再用口号式大字号；标题移入顶栏属于 T034。

## 偏差与说明

- 主按钮文字设计稿为 `#FFFFFF`，代码用 `ink-inverse`（`#FDFCFA`），差异肉眼不可见，没有为此新增白色 token。
- 紧凑选择框的菜单最小宽 128，比触发器宽时不等宽（设计稿规定等宽，但窄触发器会截断选项）。
- 超过 8 个选项时只做了菜单内滚动，没有输入过滤；目前只有“写作框架”选择可能超过 8 项。
- 手机预览设备外框新增两个只用于该处的尺寸 token：`rounded-device`（28，设计稿画框 18 的数值）与 `w-phone`（375），已写入设计系统文档。
- 页面内仍有 `mt-*` 等外边距与旧的版面结构；按第 5 节改为只用 padding / gap、标题移入顶栏、各页按画框重排，属于 T034、T035。
- `SaveStatus`、`EvidenceMark`/`EvidenceSource` 目前只在 `/design-system` 使用：正文编辑器的保存状态带冲突与错误说明，替换会丢信息，留给文章工作区任务；证据联动需要文章工作区三栏布局。
- 集成测试与 E2E 使用本机开发数据库，没有像 T017 那样新建独立 Compose 项目（本任务无迁移、无数据结构改动）。
